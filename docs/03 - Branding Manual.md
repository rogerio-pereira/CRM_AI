# Branding Manual

## Project
Internal AI-Assisted CRM Platform

## Purpose
This document defines the visual identity direction for an internal CRM system.

This is not a marketing brand.  
This system does not need slogans, campaigns, mascots, or public-facing identity.

The goal is to define enough visual direction so Figma, Google Stitch, or another UI generation tool can create consistent internal CRM screens without guessing.

---

# Visual Identity

## Product Type
Internal operational CRM.

## Users
Internal users managing leads, clients, opportunities, follow-ups, tasks, and AI-assisted sales workflows.

## Personality
The interface must feel:

- Calm
- Modern
- Minimal
- Technical
- Efficient
- Reliable
- Focused

The interface must not feel:

- Marketing-oriented
- Playful
- Corporate-heavy
- Over-designed
- Futuristic
- Cyberpunk
- Decorative

---

# Visual Direction

## Style
The UI must be:

- Dark mode only
- Soft dark, not pure black
- CRM-focused
- Minimalist
- Modern
- Functional
- Data-oriented
- Balanced in density

# Brand Color Direction

The brand color direction is:

- Cold
- Technical
- Modern
- Indigo/blue based
- Built on dark slate surfaces

## Primary Brand Color

| Purpose | Color | Hex |
|---|---|---:|
| Primary brand/action color | Indigo | `#6366F1` |

Use this color for:

- Primary buttons
- Main call-to-action elements
- Focus rings and focus borders
- Optional informational status highlights

## Active Navigation Color

| Purpose | Color | Hex |
|---|---|---:|
| Active navigation / selected nav background | Deep indigo | `#3730A3` |

Use this color for:

- Active sidebar items
- Selected navigation states

Primary buttons and CTAs use `#6366F1`, not `#3730A3`.

## Supporting Accent Color

| Purpose | Color | Hex |
|---|---|---:|
| Secondary accent / links | Blue | `#0EA5E9` |

Use this color for:

- Links
- Secondary actions
- Informational highlights

## AI Accent Color

| Purpose | Color | Hex |
|---|---|---:|
| AI-related UI | Purple | `#8B5CF6` |

Use this color for:

- AI insight labels
- AI badges
- AI suggestion panels
- AI-generated recommendation markers
- Pipeline stages: Qualification, Proposal Generation

AI color must not dominate the interface.

## Status Colors

Use intuitive functional status colors (not additional brand colors):

| Purpose | Color | Hex |
|---|---|---:|
| Success | Green | `#10B981` |
| Warning / alert | Amber | `#F59E0B` |
| Danger | Red | `#EF4444` |
| Info | Primary or accent | `#6366F1` or `#0EA5E9` |
| Neutral | Muted slate | `#94A3B8` |

## Core Background Color

| Purpose | Color | Hex |
|---|---|---:|
| Main app background | Dark slate | `#0F172A` |

Do not use pure black.

---

# Color Rules

Do:

- Use dark slate surfaces
- Use indigo `#6366F1` as the main action color
- Use `#3730A3` for active navigation backgrounds
- Use blue for secondary highlights
- Use purple `#8B5CF6` for AI-related UI and designated pipeline stages
- Use intuitive status colors for success, warning, danger, and info states
- Keep colors controlled and functional

Do not:

- Invent additional brand colors beyond the palette above
- Use neon colors
- Use heavy gradients
- Use pure black backgrounds
- Use colorful decoration
- Use light mode

---

# Typography

## Font
Use Inter.

## Typography weights
- 700 (`font-bold`) for titles, buttons, active navigation labels, CTAs, badges, and metric values
- 300 (`font-light`) for body text, table content, labels, helper text, and metadata

## Typography Style
Typography must be:

- Clean
- Readable
- Modern
- Optimized for tables, dashboards, and CRM workflows

---

# Layout Direction

The interface should prioritize:

- Sidebar navigation
- Dashboard cards
- Tables
- Kanban boards
- Detail modals
- Forms
- Follow-up/task lists
- AI recommendation panels

The layout should be mobile-first.

---

# Motion Direction

Motion should be:

- Minimal
- Fast
- Functional
- Subtle

Avoid decorative animation.

---

# AI Generation Rules

When generating UI screens from this branding manual:

1. Generate dark mode screens only.
2. Use mobile-first layout.
3. Use the primary brand color `#6366F1` for primary actions and CTAs.
4. Use `#3730A3` for active navigation backgrounds.
5. Use dark slate backgrounds, especially `#0F172A`.
6. Use blue `#0EA5E9` for secondary highlights, links, and optional info status.
7. Use purple `#8B5CF6` for AI-related UI and pipeline stages Qualification and Proposal Generation.
8. Use intuitive status colors: green success, amber warning, red danger; info may use `#6366F1` or `#0EA5E9`.
9. Use typography weight 700 for titles and buttons; weight 300 for body text.
10. Do not invent new brand colors beyond this palette.
11. Do not use heavy gradients.
12. Do not create a landing page.
13. Do not add slogans.
14. Do not use marketing copy.
15. Do not use light mode.
16. Do not use decorative illustrations.
17. Treat this as an internal CRM.

---

# Final Direction

The interface should feel like:

> A calm, modern, dark, technical internal CRM workspace for fast sales operations and AI-assisted productivity.
